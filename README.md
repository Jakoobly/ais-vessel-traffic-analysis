## Project Overview

This repository contains the implementation and analysis for the **AIDAHO IDS THAS 2026** assignment. The project focuses on working with **Automatic Identification System (AIS)** vessel tracking data using **R**, **PostgREST APIs**, **Leaflet**, **Docker**, and **Shiny**.

The assignment includes:

- Querying and analyzing AIS vessel data
- Sampling strategies for large-scale time series data
- Vessel movement and behavior analysis
- Interactive geospatial visualizations with Leaflet
- Static HTML dashboards
- Deployment of a Shiny application using Docker and Nginx

The AIS dataset contains both **static vessel metadata** and **dynamic position data**, enabling spatial and temporal vessel analysis. :contentReference[oaicite:1]{index=1}
