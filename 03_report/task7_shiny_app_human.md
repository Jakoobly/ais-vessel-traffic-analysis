# Task 7 Shiny Application Summary

The Shiny application implements Option A because Task 5 was completed. It uses the preprocessed file `01_data/task7_shiny_traffic_density.csv`, which is generated by `02_code/R/task7_prepare_shiny_data.R`. The app allows users to select a river and one or more ship types, then refresh the plot. The plot shows AIS traffic density on 2022-04-23 in 10 km bins along the selected river geometry.

The deployed app is routed through NGINX at `/ais_app/`. Static files from Task 6 remain available from the NGINX document root, including `/sample_points.html`.

The app avoids expensive interactive API requests because the required Task 5 data are prepared once before deployment and mounted read-only into the Shiny container.
